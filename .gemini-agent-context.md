# EzRoom Project Context

This document serves as a shared memory and synchronization point for AI agents (Antigravity and Gemini) working on the EzRoom Android application.

## Project Overview
- **Project Name**: EzRoom (Room Rental Management Application)
- **Architecture**: Clean Architecture / MVVM (Packages: `data`, `domain`, `ui`)
- **UI Framework**: Jetpack Compose
- **Language**: Kotlin
- **Localization**: UI is strictly in **Vietnamese**. Internal comments/docs are in **English**.
- **Theme**: Forced **Light Theme** for all screens.
- **Core Technologies**:
    - **Navigation**: Navigation Compose (centralized in `AppNavigation.kt`)
    - **Image Loading**: Coil (`AsyncImage`)
    - **Data Parsing**: Gson
    - **Maps**: Google Maps SDK with Maps Compose
    - **Icons**: Material Icons Extended

## Current State & Implementation

### 1. Navigation & Flow
- `AppNavigation.kt`: Centralized NavHost with all routes (`Screen` object).
- `MainScreens.kt`: Manages Renter and Host specific bottom navigation bars and Scaffold structures.

### 2. Renter Module (`ui.renter`)
- **Discovery**: `RenterHomeScreen`, `SearchResultScreen`, `AdvancedFilterScreen`.
- **Details**: `RenterRoomDetailScreen` (includes reviews, reporting, and chat shortcut).
- **Appointment**: `BookingFormScreen`, `RenterAppointmentListScreen`.
- **Financial**: `RenterInvoiceListScreen`, `InvoiceDetailScreen` (simulated payment).
- **Contract**: `RenterContractScreen` (signing flow from notification).

### 3. Host Module (`ui.host`)
- **Management**: `RoomManagementScreen`, `RoomFormScreen` (Create/Edit with amenity compensation amounts).
- **Details**: `HostRoomDetailScreen` (Admin view without social interactions).
- **Invoicing**: `HostInvoiceListScreen`, `CreateInvoiceScreen` (manual electricity/water unit prices).
- **Contract**: `CreateContractScreen`, `HostContractScreen` (creation and signing).
- **Dashboard**: `HostDashboardScreen` (Statistics and quick actions).

### 4. Auth & Support
- `LoginScreen`, `RegisterScreen`, `ForgotPasswordScreen`, `ChangePasswordScreen`.
- `ChatListScreen`, `ChatRoomScreen` (simulated messaging).
- `NotificationScreen` (supports type-based navigation like Contracts).

### 5. Shared Components (`ui.components`)
- `RoomCard`, `EmptyState`, `LoadingWidget`, `StatusBadge`, `CustomTextFields` (Standard & Small versions).

## Data Models & Schemas (`data.model`)

### Room
```kotlin
data class Room(
    val id: String,
    val title: String,
    val price: Long,
    val priceFormatted: String,
    val address: String,
    val detailedAddress: String,
    val description: String,
    val structure: RoomStructure,
    val floorArea: Double,
    val mezzanineArea: Double,
    val detailedAreas: List<DetailedArea> = emptyList(),
    val rating: Float,
    val images: List<RoomImage>,
    val amenities: List<Amenity>,
    val status: RoomStatus = RoomStatus.ACTIVE,

    val longitude: Double

```

## Pending Tasks / Integration Points

3. **Advanced Filtering Logic**: The backend should handle complex geospatial and range queries.
4. **Payment Gateway**: The "Payment Confirmation" flow is a placeholder. Needs real gateway integration (VNPay/Momo).
5. **eKYC Pipeline**: Identity verification is a mock UI flow. Needs real image processing or 3rd party SDK integration.
